Why the confirm: switching language mid-batch silently changes what the remaining files fetch — that's the kind of "silent wrong-episode" bug your 8bab15e commit just fixed. So when a run is in flight, the scope picker is mandatory; for a single file it just applies instantly. Native names render in their own script so you pick العربية not "Arabic".

The 5-second auto-pick is the key QoL win: in a bulk run you don't get blocked waiting to press a key — it just proceeds with your default, and the toast records what it did in History. Press A to pin the current choice as the new default (writes back to config). If sync fails (no ffmpeg), the toast turns amber and offers retry-without-sync.

Why this matters for "QoL stuff": every feature above (and the dozen config knobs you already have — UTF-8, hearing-impaired filter, auto-select, ads-file path) is also reachable here by typing part of its name. So the app stays discoverable even as features grow — no "I know there's a setting but I can't find it." It's the pattern every mature TUI from lazygit to helix converged on for exactly this reason.
