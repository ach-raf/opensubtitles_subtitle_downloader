My recommendation: A (Command Deck) as the spine, with B's file-list pane grafted in for batch runs — it's the layout that scales from "one file" to "a whole season" without changing mental model, and the keyboard-first density matches a tool you'll use often. C is the right onboarding/quick mode but too low-density as the only interface for a power tool.
